New machine? Start here

Dojo warms up your AI coding tools first.

Run this before anything else on a fresh machine — it sets up opencode, Claude Code, GitHub Copilot CLI, Codex CLI, and Aider, each wired with whatever token-saving optimizations it actually supports, and keeps them that way. It persists the whole toolchain into your shell profile and puts a live token status in every prompt — usage, cache refresh, and how close you are to the context window. Paste it, follow the prompt to log in to GitHub (SSH key or a browser code), and it clones your projects too. 

$ bash <(curl -fsSL https://raw.githubusercontent.com/Cyb3rRon1n/dojo/main/install.sh)

One maker, five tools — four computed, one explained

Built on what's real,
not assumed.

Every tool here inspects the real system before it acts on it, or computes the real number instead of letting a model guess one — real GPU VRAM, real infrastructure state, real game math. No LLM invents a number it should compute — sizing, scoring, and game math are engine-verified. (Delphi's job is different: explaining, not computing.)

  • Vulcan sized to real disk/RAM/CPU
  • Anvil sized to real GPU VRAM
  • Atlas verified on real infra, not mocks
  • Oracle engine-computed, not model-guessed
  • Delphi explains the page, never invents an answer

Self-study explainer

Delphi

A browser extension that explains the reasoning behind a practice question — why the right choice is right, why the others aren't — one click at a time. Not for live exams: nothing runs until you ask it to.

  • Chrome / Brave
  • On-device Gemini Nano or Ollama
  • Auto-detect + full-page check
  • Manifest V3
