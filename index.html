New machine? Start here

Dojo warms up your AI coding tools first.

Run this before anything else on a fresh machine. It installs and optimizes thirteen AI coding tools — RTK output filtering, knowledge-graph context, semantic editing over MCP — and sets up Orca, the GUI that runs them side by side in git worktrees. Clones your GitHub projects too. Native on Windows — no WSL required. 

$ bash <(curl -fsSL https://raw.githubusercontent.com/Cyb3rRon1n/dojo/main/install.sh)  # Linux/macOS
$ powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/Cyb3rRon1n/dojo/main/install.ps1 | iex"  # Windows

One maker, six tools — five computed, one explained

Built on what's real, not assumed.

Every tool here inspects the real system before it acts on it, or computes the real number instead of letting a model guess one — real GPU VRAM, real infrastructure state, real game math. No LLM invents a number it should compute — sizing, scoring, and game math are engine-verified. (Delphi's job is different: explaining, not computing.)

  • Vulcan sized to real disk/RAM/CPU
  • Anvil sized to real GPU VRAM
  • Atlas verified on real infra, not mocks
  • Oracle engine-computed, not model-guessed
  • Delphi explains the page, never invents an answer

AI Dungeon Master

Oracle

An LLM in the GM seat, narrating and adjudicating a real-time tabletop session in your browser — HP, AC, XP, and spell slots computed by the engine using an open tabletop ruleset, never guessed at by the model. Two-phase turns keep structured decisions schema-constrained and the prose free.

  • Web client
  • Multiplayer over websockets
  • Open tabletop ruleset
  • Any LLM provider, cloud or local
$ git clone https://github.com/Cyb3rRon1n/oracle.git
$ cd oracle && pip install -e ".[ollama]"
$ python -m server.main
$ cd web && npm ci && npm run dev

One Python server, any number of browser windows — share a session id to play together. Players on other machines need no install at all, just the page: setup walkthrough.
