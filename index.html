New machine? Start here

Dojo warms up your AI coding tools first.

Run this before anything else on a fresh machine. It installs and optimizes thirteen AI coding tools — RTK output filtering, knowledge-graph context, semantic editing over MCP — and sets up Orca, the GUI that runs them side by side in git worktrees. Clones your GitHub projects too. Native on Windows — no WSL required. 

$ bash <(curl -fsSL https://raw.githubusercontent.com/Cyb3rRon1n/dojo/main/install.sh)  # Linux/macOS
$ powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/Cyb3rRon1n/dojo/main/install.ps1 | iex"  # Windows

Jellyfin trial shows

Trials

Weekly trial shows and movies for a Jellyfin stack: it picks brand-new titles from what's trending and what your users actually watch, lets them vote 👍/👎 for three weeks, then keeps the winners and deletes the rest — and only ever touches what it added itself.

  • Jellyfin
  • Sonarr + Radarr
  • Seerr trending
  • Voting page
  • Watch-history aware
$ git clone https://github.com/Cyb3rRon1n/trials.git
$ cd trials && pip install -e ".[dev]"
$ python -m trials probe  # read-only API check

Runs as one container beside your media stack — python -m trials serve for the page and scheduler; details in the README.

Ebook library + Send to Kindle

Ebook Server

Your own ebook library with Send to Kindle — a replacement for Kindle Unlimited that works with stock Kindles. Browse and read in the browser, request a missing book and it appears in the library on its own.

  • Calibre-Web Automated
  • Shelfmark requests
  • Send to Kindle
  • VPN-only downloads
  • Optional audiobooks
$ git clone https://github.com/Cyb3rRon1n/ebook-server.git
$ cd ebook-server && ./setup.sh

setup.sh asks for a WireGuard key (or leave it blank to try it first), writes .env and starts everything in order.
