New machine? Start here

Dojo warms up your AI coding tools first.

Run this before anything else on a fresh machine — no directory to create or navigate to first, it's all absolute paths. It sets up opencode, Claude Code, GitHub Copilot CLI, Codex CLI, and Aider, each wired with whatever token-saving optimizations it actually supports. Paste it, then follow the prompt to log in to GitHub (SSH key or a browser code) and it clones your projects too. 

$ bash <(curl -fsSL https://raw.githubusercontent.com/Cyb3rRon1n/dojo/main/install.sh)

Two tools, one detection-first method

Detect the hardware.
Forge the stack.

Vulcan and Anvil are open-source CLIs that inspect what your machine actually has — CPU, RAM, and disk, or GPU VRAM — and generate a Docker Compose stack sized to it. Deterministic tier scoring, no LLM in the decision path, no manual sizing guesswork.

Detect real hardware → Recommend a tier → Generate the compose stack → Start it, or don't — your call
